#  Netflix Movies and TV Shows Data Analysis using Python

##  Project Overview
This project focuses on analyzing the Netflix Movies and TV Shows dataset using Python.

The main goal of this project is to explore Netflix content, clean the dataset, identify important patterns,
and create visualizations to understand the distribution and trends of Movies and TV Shows.

##  Project Objectives

- Clean and preprocess the Netflix dataset
- Handle missing values and duplicate records
- Analyze Movies and TV Shows distribution
- Analyze content added to Netflix over the years
- Explore ratings and genres
- Analyze country-wise content
- Extract useful insights from the dataset
- Create meaningful data visualizations

##  Technologies & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- vs code 

##  Dataset
The Netflix dataset contains information about Movies and TV Shows available on Netflix.

The dataset includes columns such as:

- `show_id`
- `type`
- `title`
- `director`
- `cast`
- `country`
- `date_added`
- `release_year`
- `rating`
- `duration`
- `listed_in`
- `description`

##  Data Cleaning
The following data cleaning steps were performed:

- Checked the dataset structure and data types
- Checked for missing values
- Handled missing values
- Checked for duplicate records
- Converted `date_added` into datetime format
- Created a new `year_added` column
- Standardized data for analysis
- Used direct column assignment to avoid unnecessary Copy-on-Write warnings
